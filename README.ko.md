# ShelfDock — 쉘프독

**작업 사이에 파일과 캡처, 문구를 잠깐 놓아두는 Windows 선반입니다.**

여러 창을 오가며 필요한 자료를 모으고, 준비되면 대상 앱으로 꺼내 쓰세요.

[English](README.md) · [사용 안내](USER-GUIDE.md) · [릴리스](https://github.com/Mintflavor/shelfdock/releases) · [문제 신고](https://github.com/Mintflavor/shelfdock/issues)

## 배포 상태

첫 Windows 11 x64 베타를 검증하고 있습니다. [출시 체크리스트](QA.md)가 완료되기 전까지 릴리스는 초안으로 유지합니다. 아직 공개 실행 파일 다운로드는 제공하지 않습니다.

공개 후에는 Releases에서 `ShelfDock-v0.2.0-beta-win-x64.zip`을 받아 전체 압축을 풀고 `ShelfDock.exe`를 실행하세요. .NET 별도 설치나 관리자 권한은 필요하지 않습니다. 미서명 베타이므로 Windows가 게시자를 확인하지 못할 수 있습니다. 보안 기능을 해제하지 마세요.

새 기기 연결은 [8자리 OTP](OTP-GUIDE.md)와 60초 내 양쪽 승인으로 진행합니다. 양쪽 PC를 업데이트하세요. 초대 링크·QR은 제거했으며 기존 연결은 유지됩니다.

## 주요 기능

- 상시 플로팅 아이콘에 드롭하고 클릭해 선반을 여세요. 닫으면 아이콘으로 돌아갑니다.
- Unraid용 Linux Docker 릴레이 패키지와 [설치 안내](RELAY-DOCKER.md)를 제공합니다.
- `Ctrl+Alt+S` 또는 트레이 아이콘으로 선반 호출.
- 로컬 파일·일반 텍스트 드롭, 캡처 이미지 붙여넣기.
- 여러 파일을 선택해 함께 드래그.
- 자주 사용하는 항목 고정, 실행 중 제거 되돌리기.
- 재실행 시 목록 복원, 한국어·영어 지원.
- 선택적으로 켜는 기기 간 선반 공유, 메타데이터 우선 표시와 검증 후 파일 수신. [페어링·릴레이 안내](P2P-GUIDE.md).

원본은 원래 위치에 그대로 있습니다. 일반 파일은 경로만 기억하며 외부 전달은 복사만 허용합니다. 선반에서 제거해도 원본을 삭제하지 않습니다. 자동 정돈은 기본 꺼짐이며, 드롭 수락은 업로드 완료를 뜻하지 않습니다.

공유는 기본 꺼짐입니다. 켜면 현재와 이후의 로컬 선반 내용을 페어링한 기기에 전송합니다. 공개 DHT에는 주소·기기 ID가 사용되며 릴레이는 통신 메타데이터를 볼 수 있습니다. 기본 제공 공용 릴레이는 없고 실제 외부망 NAT·릴레이 검증은 미완료입니다. 계정·광고·사용 추적·클립보드 자동 수집·자동 업데이트는 없습니다.

## 무료 사용과 소스 비공개

개인·교육·회사 내부 업무에서 무료로 사용할 수 있습니다. 이 버전의 사용에는 기한이 없습니다. 고지문을 포함한 공식 배포본 전체를 변경 없이 무료로 재배포할 수 있습니다.

프로그램 자체의 유료 판매, 유료 상품에 묶은 배포, 수정본 배포에는 서면 허락이 필요합니다. 소스는 비공개이며 이 저장소에는 배포 자료만 있습니다. MIT·Apache·GPL 오픈소스가 아닙니다.

[영문 약관](LICENSE.txt)과 [한국어 설명](LICENSE.ko.md)을 확인하세요. 제3자 구성요소에는 각각의 원래 라이선스가 적용됩니다.
